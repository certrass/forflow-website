# ForFlow homepage v5

[Open the remote product showcase](https://6a9c34c0776d0d9d3de29217--forflow-enterprise-suite-v3.netlify.app/#workflows)

An independent homepage design prototype focused on the product showcase. The hero contains a running workflow editor. Three scenes show supply-chain exception review, document field verification, and industrial drawing relationships using different interfaces.

The deployed preview address and deployment verification are recorded in `remote-preview.json`. The source project and unrelated production-site changes remain separate.

## Development

Install with `npm install`, run with `npm run dev`, and build with `npm run build`. Netlify preview uploads use only `dist/client` plus a noindex response header. Do not publish the repository root.

## Review

See `design-qa.md` for the executed visual and interaction checks. Full-page desktop and mobile screenshots are included in this folder. Interface records are demo data; operational buttons change local demonstration state only.

# ForFlow 首页视觉稿 v3

日期：2026-09-05。

用户反馈上一版 UI 过于粗糙、缺乏品质。本次重新设计页面构图，延续 ForFlow 的黑、白、绿色，以本次已访问的 Attio Workflows、Ask Attio 和 Databricks 首页截图作为视觉参考，由内置 Image Gen 生成。

## 本次变化

- 首屏大幅提高标题的视觉权重，采用标题左侧、说明和行动入口右侧的构图。
- 将整张后台表格拆成业务上下文、异常分析、人工确认三个相连的操作片段。
- 深色能力区突出原始资料、提取结果、人工复核的关联。
- 案例区用两张大幅案例展示替代三个小卡片，评估内容作为独立阅读入口。
- 页尾缩减为清晰的场景诊断入口和品牌收尾。

## 使用范围

这是用于确认视觉方向的静态设计稿。按钮和标签不具备网页交互，网站源码与线上首页均未修改。图内界面、名称、金额、图表和记录是设计示意；它们不是可核实的项目记录。后续实现需要替换为经核对的匿名案例内容、真实品牌资产和确定性中文排版。

完整生成提示词见 generation-prompt.txt；设计原图为 forflow-homepage-v3-design.png。上一版保留在相邻的 homepage-v2 目录。

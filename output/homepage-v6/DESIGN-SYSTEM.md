# ForFlow 首页设计系统 · 2026-09-06

本轮在独立 homepage-v6 上重做页面与产品展示的视觉系统。以 [Attio 首页](https://attio.com/#home-2026-run-sales-motions) 的现场页面、公共 CSS 和交互代码为参考，提取中性灰阶、字体层级、连续边框、留白和动效节奏。首页顺序沿用此前参考 [Dataify](https://dataify.com/) 形成的具体工作 → 产品场景 → 优势 → 能力积累 → 案例与联系。

## 动效规则

- UI 主曲线 `cubic-bezier(.33,1,.68,1)`；退出曲线 `cubic-bezier(.32,0,.67,0)`。
- 首屏进入 800 ms；滚动进入 600 ms；视图切换 500 ms；退出 180 ms。
- 看板沿用固定 DOM 卡片，跨列时抬升、轻微旋转与放大，落下后收回阴影；主卡片 1445 ms，周围卡片 550 ms 让位。卡片尺寸与位移按 ForFlow 四列内容重新适配，并非 Attio 业务组件的直接复制。
- 自动流程只在进入视野后播放一次；用户选择、筛选、切至列表、离开视野或页面隐藏时停止。支持手动重播与恢复初始状态。
- 菜单有悬停意图延迟、进入与退出过渡；支持方向键进入、Escape 关闭和焦点返回。
- 工作台引导切换后将新界面滚动至视野顶部；证据、版本与资产保持各自的操作状态。
- 减少动态效果偏好关闭 CSS 动画、卡片位移与自动播放；代码分支已核对，本轮未改变系统设置做实际偏好切换。

## 响应式

1200 px 工作台、1108 px 业务场景和 690 px 优势画布保持原生布局。小屏完整缩放呈现，点击查看细节后放大并横向浏览；打开任务详情时自动将详情移入视野。普通文案与案例卡可响应式排布，产品四列、原文/字段和图纸/关系保持原有空间含义。

能力结构默认使用已有三维渲染图，实时 Three.js 组件按需加载；保留分层、旋转、复位与返回渲染图。

## 产品演示迭代

2026-09-06 用户进一步明确重点是页面里的产品演示。重新对照 Attio 的流程展示：业务对象持续存在，界面随工作推进，结果由具体操作产生。三个场景各有独立原生界面和三个章节，避免只用静态仪表板表达能力。

- 业务：保留四列看板的卡片位移；在第二阶段展开订单与信用记录的关联，第三阶段展开负责人复核，确认后进入交接列。
- 文档：原文和字段保持左右布局，按顺序生成五个字段；选择字段同步定位原文，确认留下局部状态。暂停同时停止字段生成，重播恢复初始状态。
- 工程：从原始图纸切入六节点关系图，选中对象更新右侧档案；上下游相对泵组定义，准备清单对应当前选择，包含工程师需核对的内容。
- 播放：首次进入视野播放一次；手动操作、离开页面或画面停止。允许选章节、继续、重播；减少动态效果偏好停止自动播放与动画。章节控件放在画布外，手机可直接操作。
- 工作台：总览 → 签收证据 → 费率变更前 → 新版本复评任务；用户切换视图、搜索或操作时停止自动讲解。

本次 Chrome 检查覆盖 1440/768/390 px、播放/暂停/重播、字段原文确认、任务交接、设备选择与准备清单、手机放大和状态保留。手机四列看板、590+518 px 文档布局及 764+344 px 工程布局均保持完整；修正放大工具栏被手机样式压缩的问题。产品源文件为 ProductDemos.jsx、ScenePlayback.jsx、BusinessBoard.jsx、WorkspacePreview.jsx，局部样式为 product-films.css。

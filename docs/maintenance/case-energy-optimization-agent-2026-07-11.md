## 内容处理原则

项目方提供的材料信息量很大，但混合了政策背景、技术方案、演示数字、目标阈值和案例式叙述。本页没有把它压成营销摘要，而是保留了以下技术链：

- Modbus RTU、OPC UA、PROFINET 与厂商协议接入
- MES、WMS、APS 与 OT / IT 数据关联
- 负荷、光伏出力和短期电价三类预测
- LSTM / Transformer 与 SAC / DQN / PPO 候选方法
- 状态空间、动作空间、奖励函数和设备硬约束
- 日前计划与日内滚动优化
- PLC / DCS 指令、设备响应和控制日志
- 冷机 COP 与多设备群负荷分配示例
- 影子运行、建议模式、受控放权和人工接管
- 预测、调度、控制、生产、财务与安全六类验收证据

## 证据边界

- “国家电网合作场景”来自项目方确认，没有使用国家电网标识。
- 材料未附工厂名称、结算单、原始运行日志、第三方审计或正式验收记录。
- 收益数字、响应时延和精度值均在页面中标记为方案设定、示例测算或待验收目标。
- 公开发布前仍需项目负责人确认合作名称、可披露范围、客户引用和指标附件。

## China + Q2Q rule

Current recommended direction: Chinese people, Chinese enterprise contexts, and Q2Q / ForFlow work-unit logic. Each image should show a business problem, task boundary, AI/Agent step, human review point, evidence, and next dispatch/expansion/reassessment context. Do not show Q2Q as judging a person.

## 2026-06-24 orientation correction

C01 / C04 / C07 / C08 were regenerated as v2 after review found that some screens looked like props facing the camera. The v2 prompt rule is: screens must naturally face the people using them, not the viewer. Prefer over-the-shoulder, side, or table-level angles where the viewer sees only an oblique glimpse of abstract workflow blocks.

- `c01-home-hero-china-q2q-workunit-tablet-v2.png`: homepage hero, screen angled toward the operations lead, left negative space retained.
